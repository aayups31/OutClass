Python foundations

OffCourse explains that Monday is missing from the dictionary. The learner starts each new day at zero using totals.get(day, 0). The updated code passes the three example checks.

lesson.py
def summarize(records):
    totals = {}
    for day, minutes in records:
        totals[day] = totals.get(day, 0) + minutes
    return totals
