# A workspace with room to work

Code & learn opens with the editor and OffCourse on the right. A single compact context bar shows the course, current lesson and checkpoint action. File tabs and run controls sit directly below it. The file tree and bottom panels stay closed until requested; previous runs remain available in Output.

- **Lesson** opens course direction, assignments and practical tasks in the side panel. A blue dot signals an available practice opportunity. **Conversation**, **Sources** and **Architect** are tabs in that same panel.
- **OffCourse** toggles the teacher. Error actions open it with the recorded run attached. Hint style and additional context are under the composer's expandable controls.
- **Output**, **Terminal**, **Project** and **Notes** share one bottom strip. One panel is visible at a time. Running a file opens Output. Hiding a terminal preserves its running shell; stopping it remains a separate action.
- **Focus editor** hides both sidebars, the file tree, lesson header and bottom panels. Exit restores the previous layout and open panel. Code and assignment drafts remain mounted when their panels are hidden.
- Drag panel dividers, or focus them and use the arrow keys. Sizes and sidebar visibility are remembered. Layout options contains assistant placement and Reset layout.
- A narrow icon rail keeps workspace navigation available. Files and Courses share the optional explorer; the course name opens course switching. More tools contains practice, live work, ideas, checkpoints, editor connections, Academy, Creator Studio and GTM. Theme controls are under Layout options while coding.

On narrower windows, Code and Assistant switch between full-width views. The mobile navigation keeps the same destinations under More tools.

The layout v3 migration preserves previously resized dimensions, opens OffCourse and closes the explorer for the new default. Future visibility choices are remembered. It does not change learning files, checkpoints, notes, account settings or credentials.
