## OutClass Learn

The Windows workspace for self-learners. Keep courses, code, checkpoints, and OffCourse together. Open a hosted Academy course from **My courses → Open an Academy course**.

## OutClass Educator

Build courses in Academy, create previews in Creator Studio, and prepare launch posts in GTM. Preview an Academy release in the built-in Learn workspace.

Both installers are Windows x64 previews. The Udemy browser companion and editor extension connect to Learn. Educator keeps its own local profile. Existing authoring drafts from the combined app stay in that app’s data until you migrate them.
