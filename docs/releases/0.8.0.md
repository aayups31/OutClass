# OutClass 0.8.0 · Connected agents preview

This Windows preview turns the four product specialists into bounded task workspaces that produce editable, source-linked work. Learn keeps the learner in control of their code and attempts.

- **Learn / OffCourse:** one compact context bar, file tabs directly below, a narrow navigation rail and the teacher open on the right. Files and Courses share an optional explorer. Resize panels, switch tools or focus the editor without losing unfinished work.
- **Academy Architect:** produce a lesson package with a practical task, observable acceptance criteria, progressive hints, reflection and a changed-requirement challenge. Review and apply it to a new course revision, then release it into Learn. Instructor starter files are preserved.
- **Creative Director:** produce a source-grounded script and, with selected owned footage, an editable timeline. Import SRT/WebVTT captions, search timed passages and add a matching moment as a scene. Timed proposals must fit their cited cues and actual footage duration. Rendering and playback review remain separate actions.
- **Growth Strategist:** produce distinct posts for selected channels, review their evidence and prepare real local promotion/campaign drafts through the existing channel validators. Attach the required media and review the composer before scheduling or publishing.
- **Analytics:** produce evidence briefs and bounded experiment plans from recorded reports and provider observations. Missing measurements remain unknown; model interpretations are kept separate from actual metrics.
- **Connected specialists:** offer a reviewed task output directly to another agent. The receiving specialist explicitly accepts it as labeled source context. Academy handoffs require a release matching the current course revision.
- **Continuity:** task progress, validation findings, exact review hashes and delivery receipts persist locally. Reapplying a successful task does not duplicate its delivery. Interrupted tasks require an explicit retry. Native social connections now use Windows account encryption and restore after restart; expired tokens require reconnection.

Each task uses at most one or two calls through the configured personal, local or included AI connection. The second call, when authorized, corrects validation findings. Model use is explicit; background retries do not consume credits.

## Use the task workspaces

1. Install the Windows preview and complete Setup. Choose your learning folder and an AI connection in Settings.
2. Open Academy, save your course material and select a lesson. Describe a task to its specialist, then run, inspect sources and review the result before applying.
3. Release a reviewed course revision to preview its learner assignments in Learn. Create a source-linked Creator draft from that release.
4. In Creator Studio, optionally import owned footage and its timed captions. Review the proposed script/timeline, render and inspect playback.
5. In GTM, prepare channel drafts, attach eligible media and inspect each native-style composer. Connect approved platform accounts only when ready to publish. Record or refresh real measurements, then ask Analytics for the next bounded experiment.

## Preview boundaries

This is an unsigned Windows preview. Structural checks and smoke tests do not establish expert editorial judgment or learner outcomes. Human review and real learner/creator trials remain necessary. Caption indexing is not automatic transcription or visual scene recognition. Platform previews approximate each platform's current presentation; the platform controls its final rendering.

YouTube, LinkedIn, X and Instagram require their developer-app configuration, eligible accounts and approved scopes. Downloads do not supply those credentials. The included-AI service remains an owner test environment: Resend uses its test sender and Stripe is in test mode. Public email, live billing, signed distribution and Chrome Web Store approval are separate launch gates.
